htmx Kanban board from a server-rendered table

The server renders a plain card table for three teams; Lattice turns it into a Kanban board with no mount code, and htmx handles the swaps, the out-of-band update and the save. A stand-in server answers htmx's requests in your browser, so nothing leaves the page.

Try the five steps

  1. Built on load. The cards were a server-rendered table; the board replaced it on load, with Todo, Doing and Done columns.
  2. Move a card. Drag a card to the next column. lattice:kanban-change is posted with hx-post and the server confirms below the board.
  3. A refused drop. Drag a Todo card straight to Done. The workflow rule refuses it, the card stays put and nothing is posted.
  4. Out of band. Press "Server reassigns one card". One card comes back out of band and its owner changes in place.
  5. Back. Pick a team, then press the browser Back button. The previous cards return, with the board rebuilt.
